# assets/
>Ce dossier contient toutes les ressources globales du projet WebPulse-Engine.

### Structure
- **branding/** — Logos, bannières, visuels officiels
- **design/** — Guides de style (palette, typographie, composants)
- **media/** — Captures d’écran, images promotionnelles
- **icons/** — Icônes SVG utilisées dans la documentation ou les modules
- **docs-assets/** — Ressources partagées entre README, releases et documentation

### Bonnes pratiques
- Utiliser des formats optimisés (SVG, WebP)
- Garder des noms explicites
- Ne pas stocker de fichiers lourds inutiles
- Centraliser les visuels pour éviter les duplications
