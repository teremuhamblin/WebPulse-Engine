### 🧩 Structure du dossier **docs/**
Ce dossier contient le site web statique officiel de la division **OPEN‑SOURCES de WebPulse‑Engine.** 
Il est entièrement optimisé pour ***GitHub Pages*** et déployé automatiquement via ***GitHub Actions.***

```text
docs/
 ├─ README.md 
 ├─ index.html → Page principale (cyber‑marketing)
 ├─ css/
 │   └─ cyber.css → Style néon cyber optimisé
 ├─ js/
 │   └─ main.js → Scripts légers, sécurisés, sans tracking
 ├─ img/
 │   └─ logo.svg → Logo officiel WebPulse‑Engine
 │   └─ shields.svg → Icônes / décorations (optionnel)
```

###⚡ Mission du module ***OPEN‑SOURCES***
>OPEN‑SOURCES est la surface publique de WebPulse‑Engine.  
Il expose uniquement :
   - la documentation statique  
   - les informations de release  
   - la roadmap  
   - le changelog  
   - les liens vers le dépôt GitHub  

- Aucune donnée sensible, aucun backend, aucune API n’est exposée ici.

---

### 🎨 Design cyber‑marketing
- Le site utilise :
   - un thème néon cyber (accent turquoise / rouge)  
   - un fond grid technique façon SOC / Ghost Recon  
   - des composants statiques durcis  
   - un style sans frameworks lourds (HTML + CSS pur)  
   - des assets optimisés (SVG, WebP)

- Conçu pour être extrêmement réduit en surface d’attaque :
   - aucun script tiers  
   - aucun cookie  
   - aucun tracking  
   - liens externes durcis (noopener noreferrer)  
   - JS minimal, auditable, sans dépendances  

---
